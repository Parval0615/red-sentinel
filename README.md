# Agent Runtime Security Lab

Agent 运行时安全实验工作区。

**远程仓库：** https://github.com/Parval0615/Agent-Runtime-Security-Lab

## 快速开始

1. 克隆或打开本仓库
2. 在 `experiments/` 或 `projects/` 下创建你的实验目录
3. 参考根目录 [AGENTS.md](./AGENTS.md) 了解 Agent 协作约定

## 结构

| 目录 | 用途 |
|------|------|
| `experiments/` | 短期实验、概念验证 |
| `projects/` | 较完整的子项目 |

## 说明

本仓库由 Cursor Agent 初始化。各子项目可独立管理依赖与文档。
